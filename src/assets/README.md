La imagen `oficinas-medellin.png` fue suministrada por el cliente para esta landing
como `Oficinas modernas al atardecer en Medellín.png`.
Se utiliza como imagen empresarial de referencia, no como fotografía de la sede.
Astro genera las versiones responsivas WebP y la imagen JPEG para compartir.

`trabajo-negocios.png` es una imagen general generada con la herramienta integrada
ImageGen para “Quiénes somos”. No representa al equipo real de RPiedrahíta.
El prompt exacto se conserva en `trabajo-negocios.prompt.txt`.
La imagen se configura en `firma.imagenNosotros`, en `src/data/sitio.ts`.

`conversacion-empresarial.jpg` es una fotografía editorial de referencia generada
para el bloque de llamado a la acción (“Conversemos sobre el futuro de su empresa”),
ambientada con profesionales colombianos en una oficina moderna con vista al valle
de Medellín. No representa al equipo real de RPiedrahíta.
